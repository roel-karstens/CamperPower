# ADR-002: Safety and Liability Boundary

## Status
Accepted

## Context
CamperPower operates in a technical domain where incorrect recommendations can lead to unsafe electrical outcomes.

## Decision
The product will provide low-voltage sizing and compatibility guidance only, with explicit prohibition on procedural high-risk mains wiring guidance.

## Consequences
Positive:
- Reduced liability exposure.
- Clear trust posture and user expectations.
- Better compliance alignment.

Tradeoffs:
- Some advanced users may request deeper installation instructions.
- Requires clear referral paths to qualified professionals.

## Implementation Rules
- Mandatory warning states for uncertain compatibility.
- Safety disclaimer shown before actionable output.
- "Consult a qualified professional" prompts in critical contexts.
