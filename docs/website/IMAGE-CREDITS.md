# Image Credits

## NL
Deze pagina vermeldt de herkomst van beelden die op CamperPower worden gebruikt.

Onze uitgangspunten:
- We gebruiken alleen beelden met duidelijke gebruiksrechten.
- We vermelden per beeld minimaal: maker, bron-URL en licentie.
- We kiezen vooral beelden met inhoudelijke relevantie voor camper-elektra, off-grid gebruik en technische context.

### Hoe lees je deze lijst
- `Bestandsnaam`: naam van het beeldbestand in het project.
- `Pagina/sectie`: waar het beeld zichtbaar is.
- `Maker`: fotograaf of organisatie.
- `Bron`: originele publicatielink.
- `Licentie`: type gebruiksrecht.

## EN
This page lists image sources used on CamperPower.

Our principles:
- We use images with clear usage rights.
- For each image, we provide at least: creator, source URL, and license.
- We prioritize context-relevant imagery for camper electrical systems, off-grid usage, and technical topics.

### How to read this list
- `File name`: image file name used in the project.
- `Page/section`: where it appears.
- `Creator`: photographer or organization.
- `Source`: original publication URL.
- `License`: usage rights.
