# CamperPower Product Definition Summary

## Product Vision
CamperPower becomes the independent calculation and decision layer for camper owners upgrading to lithium and solar. The product combines practical system sizing, compatibility checks, and safety-first guidance in one flow.

## Target Users
1. Camper or caravan owners upgrading older electrical installations.
2. DIY bus-camper builders.
3. Travelers deciding between power station and fixed installation.

## Job To Be Done
"When I want to run off-grid safely, I need to know which battery, solar, and charging setup matches my usage without damaging components or creating unsafe wiring."

## Key User Problems
- Confusion about BMS, MPPT, and DC-DC interactions.
- Compatibility uncertainty with older EBL/charger setups.
- Contradictory sizing rules from different sources.
- Fear of overpaying or choosing unsafe configurations.

## Value Proposition
A single independent configurator:
- Input: daily usage and autonomy target.
- Output: battery, solar, charger, cable, and fuse recommendation.
- Confidence layer: compatibility checks, visible assumptions, safety warnings.

## Monetization Model
- Affiliate revenue from components and power stations.
- Future expansion to installer leads.
- KPI focus: tool starts -> result views -> list exports -> outbound clicks.

## Positioning
- Not a webshop.
- Not a brand-specific blog.
- Not an unstructured forum.
- It is a neutral technical recommender with documented rules.

## MVP Scope
1. Usage calculator and sizing engine.
2. 3-step recommendation flow.
3. Bill of materials with outbound pricing links.
4. Compatibility checklist for lithium migration.
5. Safety disclaimers and "consult a professional" gates.

## Non-Goals (MVP)
- Full electrical design for 230V mains circuits.
- Installation instructions for high-risk operations.
- Product stock management or direct checkout.

## Success Criteria (first 6 months)
- >= 90% page indexation on MVP pages.
- First measurable outbound affiliate clicks in first quarter after launch.
- >= 2 accepted affiliate programs with sustainable payouts.
- Clear evidence that users complete the calculator flow.
