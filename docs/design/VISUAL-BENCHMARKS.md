# CamperPower Visual Benchmarks

## Reviewed References
- https://puurwatt.nl/
- https://mymoneymile.com/
- https://macroatlas.vercel.app/

## What Works Across These References
1. Question-led narrative
- Headlines start from user decisions, not product features.

2. Method transparency
- Sites communicate assumptions, dates, and limits near outputs.

3. Utility-first layout
- Clean sections with clear hierarchy and low cognitive noise.

4. Trust through clarity
- Disclaimers, method pages, and source pages are visible.

5. Real imagery
- Photography supports topic context rather than generic abstract visuals.

## CamperPower Translation
- Hero and section titles should be framed as practical user questions.
- Every calculator recommendation should expose assumptions and boundaries.
- Footer should always surface methodology, privacy/disclosure, and image credits.
- Visual style should feel editorial and technical, not startup-generic.

## Implementation Notes
- Build tokenized design system first (color/type/spacing).
- Apply same card grammar and CTA style across all flows.
- Keep one strong accent color and one support accent only.
- Review all pages against the Design QA checklist in `DESIGN.md`.
