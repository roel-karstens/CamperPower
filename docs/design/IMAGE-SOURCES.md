# CamperPower Image Sources and Credits Policy

## Purpose
Ensure all imagery in CamperPower is high quality, context-relevant, legally usable, and transparently credited.

## Approved Source Types
1. Original photography created for CamperPower.
2. Licensed editorial/stock photography with clear commercial rights.
3. Creative Commons images that allow commercial reuse with attribution.
4. Manufacturer media only when product usage rights are explicitly granted.

## Not Allowed
- Random scraped internet images.
- AI-generated images without disclosure and rights review.
- Decorative images with no topical relevance.
- Images with unknown license status.

## Attribution Standard
Each published image must have:
- Title or short description.
- Creator name.
- Source URL.
- License type and link.
- Date accessed.
- Any edits performed.

## Public Credits Page Requirements
Include a dedicated "Image credits" page in the website footer with:
- A table of all non-original images.
- Clear mapping from image file name to source and license.
- Separate section for icons/illustrations if applicable.

## Internal Registry Template
Use this structure in a tracking sheet or markdown table:

| File Name | Placement | Creator | Source URL | License | Accessed | Notes |
|---|---|---|---|---|---|---|

## Editorial Style Rules
- Prefer real scenes over staged marketing renders.
- Show practical contexts: batteries, wiring bays, solar panels, camp setups.
- Keep color grading natural and believable.
- Avoid cliché visuals that reduce credibility.

## Compliance Check Before Publish
1. Verify license rights and attribution data completeness.
2. Confirm relevance to page topic and user question.
3. Confirm alt text quality and accessibility.
4. Confirm image size/performance optimization.
