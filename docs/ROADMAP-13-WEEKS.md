# CamperPower 13-Week Delivery Roadmap

## Objective
Reach an evidence-backed MVP launch with measurable trust and monetization signals.

## Phase 1: Validation and Framing (Weeks 1-2)
- Confirm search demand and intent clusters (NL/BE).
- Validate affiliate partner acceptance and payout viability.
- Finalize legal/compliance boundaries.
- Produce go/no-go decision.

## Phase 2: Product and Rule Foundations (Weeks 3-5)
- Freeze input/output schema for calculator.
- Implement initial formula rules and tests.
- Build compatibility rule skeleton and confidence states.
- Draft disclaimer and disclosure UX copy.

## Phase 3: MVP Build (Weeks 6-9)
- Implement multi-step configurator frontend.
- Integrate backend calculation endpoint.
- Add export/share and outbound link tracking.
- Instrument funnel analytics events.

## Phase 4: Hardening and QA (Weeks 10-11)
- Run scenario regression suite.
- Conduct expert review for high-impact rules.
- Fix UX friction points from pilot users.

## Phase 5: Launch and Learn (Weeks 12-13)
- Soft launch with 12-15 core pages.
- Review indexation, tool completion, outbound clicks.
- Decide scale, pivot, or tighten positioning.

## Weekly Operating Rhythm
- Monday: metrics review and priority setting.
- Mid-week: shipping and test checkpoint.
- Friday: decision log update and risk review.

## Exit Criteria
- Reliable and explainable recommendations live.
- Compliance and safety messaging complete.
- Initial conversion signals detected.
